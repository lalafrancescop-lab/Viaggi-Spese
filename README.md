# Viaggi & Spese — modello vuoto

App di tracciamento spese di viaggio, un solo file HTML autonomo. Questa è la versione **template**: parte vuota, pensata per essere data a chiunque voglia tracciare i propri viaggi in autonomia.

I dati restano solo nel browser di chi la apre (IndexedDB/localStorage) — mai in questo repository, e mai condivisi con nessun altro utilizzatore dello stesso link.

Pubblicata con GitHub Pages: apri l'indirizzo mostrato in alto a destra in questa pagina, sotto "About" (oppure Settings → Pages).
